# Hi, I'm Sana

Android developer and Steam Frame enthusiast. Most of my work is Android app development on Arm: Kotlin and Java over the NDK, JNI, Vulkan and OpenXR, with some native Linux arm64 on the side.

Lately I spend my spare time porting things to Valve's Steam Frame, whatever catches my fancy: VR games, streaming clients, the odd tool.

## Projects

- [GalaxyQuest-steam-frame](https://github.com/simplysanatori/GalaxyQuest-steam-frame): Super Mario Galaxy in VR as a native Linux arm64 build on the Frame's own SteamVR
- [Wiicompiled_VR-PLUS-steam-frame](https://github.com/simplysanatori/Wiicompiled_VR-PLUS-steam-frame): Mario Kart Wii VR running standalone on the Frame at 90 Hz
- [moonlight-xr-steam-frame](https://github.com/simplysanatori/moonlight-xr-steam-frame): Moonlight XR for Frame, a native Linux arm64 game streaming client on the Frame's own SteamVR, with hardware decode
- [moonlight-xr-lepton](https://github.com/simplysanatori/moonlight-xr-lepton): Moonlight XR game streaming on the Frame through Lepton, Valve's Android container

## How I work

These ports are AI-assisted. I lean on LLM coding tools for a lot of the code, which is how one person turns a port around in days rather than months; I pick the targets, direct the work, test on the headset and own the results. Each repo says so in its README.
